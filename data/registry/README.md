# Реестр проверенных фактов

Агент берёт профстандарты, коды трудовых функций, нормативные акты и (по возможности) литературу ТОЛЬКО отсюда.
Всё, чего здесь нет, выводится с пометкой `[не подтверждено]`. Реестр наполняется при сверке с первоисточниками
(этап 4), каждая запись — с URL источника и датой проверки. GigaChat реестр не пишет.

Файлы:
- `norms.json` — нормативные акты (закон/приказ/письмо, номер, дата, точное название, статус действия, тип программ).
- `profstandards.json` — профстандарты: код, название, приказ (номер, дата), ОТФ и ТФ с кодами и названиями.
- `ru_ai_services.json` — ИИ-сервисы, доступные в РФ без обхода ограничений (для программ вроде запроса 2).
- `literature.json` — книги и документация с выходными данными (по мере наполнения).

Поля статуса: `"status": "verified"` (есть `source_url` и `checked_at`) или `"to_verify"` (нельзя выводить без пометки).
